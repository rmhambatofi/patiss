# Tokens du design system vitrine

Copie des fondations de la maquette « Tah Patisserie Vitrine Mobbin Couleurs Airbnb »
(projet Claude Design https://claude.ai/design/p/5ab6b005-c8df-4b0d-9a66-9e12bbac649d) :
structure et géométrie Mobbin (`uploads/DESIGN-mobbin.md`), couleurs Airbnb (`uploads/DESIGN-airbnb.md`).

Ne pas éditer à la main : une nouvelle valeur se décide dans la maquette puis se recopie ici.
Le branchement Tailwind et les classes de composants sont dans `resources/css/app.css`.
